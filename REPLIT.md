# Деплой на Replit

Пошагово. Цель — бот работает круглосуточно, не зависит от вашего компьютера.

> Порядок проекта: **сначала тест на своём аккаунте → потом Linko → потом прод.**
> Этот файл про то, как поднять бота на сервере для теста и для боя.

---

## 0. Перед началом

Нужны три вещи под рукой:

- `BOT_TOKEN` — токен бота (уже есть)
- `GEMINI_API_KEY` — ключ модели (уже есть)
- строка подключения к базе — получим на шаге 2

---

## 1. Импортировать проект

1. Зайти на **replit.com**, войти.
2. **Create Repl → Import from GitHub**
3. Вставить: `https://github.com/Raazzyy/bot-automization`
4. Ветка: **`poluavtomat`** (не main — в ней полуавтомат)
5. Replit определит Node.js сам.

---

## 2. Завести базу данных

Встроенная база (в файле) на сервере **не годится** — при каждом передеплое
теряется. Нужен обычный Postgres. Бесплатного хватает с запасом.

1. Открыть **neon.tech**, войти через GitHub.
2. **Create project** → регион ближе к Европе (Frankfurt).
3. Скопировать **Connection string** — выглядит так:
   `postgresql://user:pass@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`

## 4. Проверить базу до запуска

В Replit открыть **Shell** (терминал) и выполнить:

```
npm install
npm run test:db
```

Должно пройти пять галочек: подключение, схема, запись, чтение, удаление.
Если база не отвечает — проблема в `DATABASE_URL`, дальше идти нет смысла.

---

## 5. Развернуть

1. Сверху — **Deploy**.
2. Выбрать **Reserved VM**.

> **Важно: именно Reserved VM, не Autoscale.** Autoscale дешевле, но он
> усыпляет приложение без веб-трафика, а наш бот опрашивает Telegram
> постоянно. На Autoscale он будет спать и пропускать сообщения.

3. Команда запуска: `npm start` (уже прописана в `.replit`).
4. **Deploy**.
5. В логах дождаться строки **«Бот слушает обновления»**.

---

## 6. Локальный запуск и решение конфликтов (DISABLE_BOT_POLLING)

Telegram отдаёт обновления только одному процессу polling. Если бот одновременно запущен на сервере Replit и у вас на компьютере (`npm run dev`) с одним токеном, Telegram вернёт ошибку `409 Conflict: terminated by other getUpdates request`.

Чтобы тестировать локально без остановки сервера Replit:
1. **Через Secret на Replit (Рекомендуется)**:
   - В Replit перейдите в **Secrets** (иконка замка) и установите `DISABLE_BOT_POLLING` = `true`.
   - Сервер Replit, веб-панель управления CRM (`/admin`), база данных и API продолжат работать в штатном режиме 24/7!
   - При этом процесс опроса Telegram на сервере деактивируется, освобождая токен для локального тестирования на вашем ПК (`npm run dev`).
   - Когда закончите локальные тесты — верните в Secrets `DISABLE_BOT_POLLING` = `false`.
2. **Либо классический способ**: просто нажмите кнопку «Stop» в консоли Replit на время локального запуска бота.

- Написать боту **@Tesssttst_bot** → «Старт» → любое сообщение.
- Карточка должна прийти в группу.
- **Закрыть вкладку Replit** и написать боту ещё раз — карточка всё равно
  приходит. Значит бот живёт на сервере, а не в браузере.

Или настроить авто-деплой при пуше в ветку.

## Сколько стоит

| | В месяц |
|---|---|
| Replit Reserved VM | ~$20 |
| Neon Postgres | бесплатно |
| Gemini (на тесте) | бесплатно |
| **Итого на время теста** | **~$20** |

В бою добавится платный Gemini (~$5) — когда в модель пойдёт реальная
переписка, бесплатный тариф использовать нельзя, Google берёт данные
на обучение.

## Если что-то не так

- **Бот не отвечает** → в логах Replit искать ошибку. Чаще всего `BOT_TOKEN`
  или два запущенных бота (шаг 6).
- **Карточки не приходят в группу** → неверный `ASSIST_CHAT_ID`, или бот
  не добавлен в группу.
- **База недоступна** → `npm run test:db` в Shell покажет причину.
- **Ошибки 403 Linko в логах** → это ожидаемо, External API ещё не открыт,
  на полуавтомат не влияет.
